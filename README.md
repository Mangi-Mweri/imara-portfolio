# Imara — petty cash app (case study)

The public page for Imara, a petty cash and expense approval app for Android, Windows, macOS and Linux.

**Live page:** https://mangi-mweri.github.io/imara-portfolio/

## What is here
- `index.html` — the case study page
- `shots/` — screenshots from the app's own tests (sample data only)
- `Imara.apk` — the Android app, version 1.3.0

## Try the app
1. On an Android phone, open the live page and tap **Download for Android**.
2. Open the file. If Android blocks it, allow your browser to install apps, then tap **Install**.
3. Open Imara and tap **Sign up**. Any 8-digit number works as the ID for this demo.
4. A manager approves new accounts. Ask Brian to approve yours, or for a manager demo sign-in.
5. Tap **+** to send a request and watch it move from waiting to paid.

The app's source code is kept in a private repository.

## Updating this page
Replace `Imara.apk` and the files in `shots/`, change the version number in `index.html`, then commit and push. GitHub publishes the change in about a minute.
